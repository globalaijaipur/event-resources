# 📁 Event Resources – Global AI Jaipur

Welcome to the official repository for **Global AI Jaipur**'s post-event resources. This repository hosts presentation slides, code samples, reference links, recordings (if available), and any supplementary material shared during our events.

## 📌 Repository Structure
Each event has a dedicated folder, following this naming convention: "***Event-Name_YYYY-MM-DD***" <br>
**Example:**
*LLMs-RAG-Webinar_2025-05-03*

---

## 🔍 What's Inside

Each event folder typically includes:
- 🎤 **Speaker Slides**  
- 🧑‍💻 **Code Examples / Notebooks**  
- 📚 **Recommended Reading / Resources**  
- 📹 **Event Recordings** (when available)  
- 📝 **Notes / Summary**

---

## 🤝 Contribution

If you attended one of our events and would like to contribute notes or additional materials, feel free to open a **Pull Request (PR)** in the relevant folder.  
Please follow the naming convention and maintain a clean structure for consistency.
